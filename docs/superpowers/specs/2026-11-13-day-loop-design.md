# ขั้นที่ 1: วงจรหนึ่งวันของชาวสวน

วันที่: 2026-11-13 · สถานะ: อนุมัติแล้ว สร้างเสร็จ 2026-11-13

## เป้าหมายใหญ่ของเกม

เกมจำลองชีวิตเกษตรกรไทยแบบครบวงจร: ทำนา ทำไร่ ทำสวน ปลูกผัก ตกปลา เลี้ยงสัตว์
และใช้ชีวิตในหมู่บ้าน เป็นเกมของเราเองในแนวเดียวกับเกมฟาร์มคลาสสิก ไม่ลอกชื่อ ตัวละคร
ภาพ หรือแผนที่ของเกมใด

เจ้าของโปรเจกต์พูดเองว่าอยากได้ "ครบทุกรสชาติของชีวิตคนการเกษตร" และเลือกให้สร้างแบบ
ทำวงจรหนึ่งวันให้เล่นได้จริงก่อน แล้วเติมทีละระบบ

## วิธีสร้างที่พิจารณา

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| 1. วงจรหนึ่งวันก่อน แล้วเติมทีละระบบ **(เลือกทางนี้)** | ทุกขั้นเล่นและติชมได้ | ช่วงแรกเกมดูโล่ง |
| 2. วางโครงทุกระบบพร้อมกันแบบตื้น | เห็นภาพรวมเร็ว | ไม่มีอะไรสนุกจริงไปอีกนาน แก้ทีหลังยาก |
| 3. ทำแผนที่และภาพก่อน | ดูดีเร็ว | เสี่ยงรื้อแผนที่เมื่อระบบเปลี่ยน |

## ลำดับทั้งเกม (ข้อเสนอของ Claude)

1. วงจรหนึ่งวัน: ปลูกผัก ขาย ซื้อเมล็ด (เอกสารนี้)
2. ปฏิทิน ฤดู และดินฟ้าอากาศ
3. ตกปลา
4. นาข้าว
5. สวนผลไม้
6. สัตว์เลี้ยง
7. หมู่บ้าน เพื่อนบ้าน งานประเพณี
8. ภาพและเสียงแนวไทย (เลื่อนขึ้นมาทำก่อนได้ถ้าอยากเห็นหน้าตาเร็ว)

แต่ละขั้นจะมีเอกสารออกแบบของตัวเอง

## ขั้นที่ 1 ทำอะไร

ผู้เล่นตื่นเช้า พรวนดิน หว่านเมล็ด รดน้ำ เก็บผักที่โตแล้วใส่ลังส่งของ ซื้อเมล็ดเพิ่มที่แผงขาย
แล้วเข้านอน เช้าวันใหม่ได้เงินจากของที่ส่ง พืชที่รดน้ำแล้วโตขึ้นหนึ่งขั้น
ถือว่าสำเร็จเมื่อเล่นต่อเนื่องได้หลายวันโดยเงินงอกเงยจากการวางแผนปลูก และปิดเกมแล้วกลับมาเล่นต่อได้

### หน้าจอ

```
┌──────────────────────────────────────────────────────────┐
│ วันที่ 3   08:40        ฿ 620        แรง ▓▓▓▓▓▓▓░░░        │
│                                                          │
│  ┌────┐                                   ┌──────┐       │
│  │บ้าน│  [ลังส่งของ]                       │แผงขาย│       │
│  └─▯──┘                                   └──────┘       │
│                                                          │
│        ░░ ▒▒ ▒▒ ░░ ░░     ░ ดินพรวนแล้ว                   │
│        ▒▒ ♣  ♣  ▒▒ ░░     ▒ ดินรดน้ำแล้ว                  │
│        ░░ ♣  ☺→ ░░ ░░     ♣ ต้นผัก  ☺ ผู้เล่น              │
│                                                          │
│        [1 จอบ] [2 บัวรดน้ำ] [3 เมล็ดผักบุ้ง x5] [4 มือ]     │

```

แผนที่จอเดียว 20×12 ช่อง (ขนาดเดิมของโปรเจกต์) มีบ้าน ลังส่งของ แผงขายเมล็ด และพื้นที่ปลูก

### การควบคุม

- เดิน: WASD หรือลูกศร
- ใช้ของที่ถืออยู่กับช่องตรงหน้า: Space (เปลี่ยนจากของเดิมที่ทำกับช่องใต้เท้า)
- เลือกของ: ปุ่ม 1–9
- คุยหรือเปิดสิ่งของ (ประตูบ้าน ลังส่งของ แผงขาย): E

### กติกา (ตัวเลขทั้งหมดเป็นข้อเสนอของ Claude ปรับได้ในไฟล์เดียว)

**เวลา**
- วันเริ่ม 06:00 เวลาเดิน 10 นาทีในเกมต่อ 5.5 วินาทีจริง หนึ่งวันยาวราว 10 นาทีจริง
- เข้านอนที่ประตูบ้านเมื่อไรก็ได้
- ถึง 24:00 แล้วยังไม่นอนจะหมดแรงล้มหลับ เช้าวันใหม่แรงเหลือครึ่งเดียว
- เวลาหยุดเดินขณะเปิดเมนูร้านหรือหน้าสรุปวัน

**แรงกาย**
- เต็ม 100 พรวนดินใช้ 4 รดน้ำใช้ 2 หว่านเมล็ดใช้ 1 เก็บเกี่ยวใช้ 1
- แรงหมดแล้วใช้เครื่องมือไม่ได้ แต่ยังเดิน ซื้อของ และเข้านอนได้
- นอนตามปกติแรงกลับมาเต็ม

**ดินและพืช**
- หญ้า → พรวนเป็นดิน → หว่านเมล็ดได้ → รดน้ำได้วันละครั้ง
- ตอนขึ้นวันใหม่ พืชที่รดน้ำแล้วโตหนึ่งวัน พืชที่ไม่ได้รดไม่โตแต่ไม่ตาย ดินกลับมาแห้งทุกเช้า
- เก็บเกี่ยวแล้วช่องกลับเป็นดินพรวน

| พืช | วันที่ใช้โต | ราคาเมล็ด | ราคาขาย |
|---|---|---|---|
| ผักบุ้ง | 3 | 10 | 25 |
| ถั่วฝักยาว | 5 | 25 | 70 |
| ฟักทอง | 8 | 50 | 160 |

**เงินและของ**
- เริ่มเกมมี 200 บาท กับเมล็ดผักบุ้ง 5 เมล็ด
- กด E ที่ลังส่งของเพื่อใส่ผลผลิตทั้งหมดในกระเป๋า ได้เงินตอนเช้าวันถัดไป พร้อมหน้าสรุปว่าขายอะไรได้เท่าไร
- แผงขายเมล็ดเปิด 08:00–17:00
- กระเป๋านับจำนวนเป็นชนิด ยังไม่จำกัดจำนวนช่อง

**เซฟ**
- เซฟอัตโนมัติทุกครั้งที่ขึ้นวันใหม่ เก็บในเบราว์เซอร์ (localStorage) มีเลขรุ่นของไฟล์เซฟ
- เปิดเกมแล้วเล่นต่อจากเซฟล่าสุด มีปุ่มเริ่มเกมใหม่ที่ต้องยืนยันก่อน
- ถ้าไฟล์เซฟอ่านไม่ได้ ให้แจ้งผู้เล่นและเริ่มเกมใหม่ ไม่ให้เกมค้าง

## โครงสร้างโค้ด

- `src/rules/` กติกาเกมล้วน ๆ ไม่ import Phaser: เวลา แรงกาย ดินและพืช กระเป๋า ร้านค้า การขึ้นวันใหม่ เซฟ
  ทดสอบได้โดยไม่ต้องเปิดเบราว์เซอร์
- `src/data/` ตารางพืชและตัวเลขสมดุล
- `src/scenes/` ฉากฟาร์ม (วาดสถานะและส่งคำสั่งจากปุ่มกด) ฉาก HUD ซ้อนด้านบน เมนูร้านและหน้าสรุปวัน
- สถานะทั้งเกมเป็นข้อมูลก้อนเดียวที่แปลงเป็น JSON ได้ เพื่อให้เซฟและทดสอบง่าย
- ทดสอบกติกาด้วย Vitest ตรวจเกมจริงในเบราว์เซอร์ของแอป

## สิ่งที่ไม่ทำในขั้นนี้

ฤดูและอากาศ ตกปลา นาข้าว สวนผลไม้ สัตว์ เพื่อนบ้าน งานประเพณี เสียง ภาพจริง (ยังเป็นรูปทรงสี)
จอยเกม มือถือ การอัปเกรดเครื่องมือ การเติมน้ำบัวรดน้ำ

## สิ่งที่ต้องไม่เกิด

- งานประจำวันรู้สึกเป็นภาระจนไม่อยากเล่นต่อ
- ลงโทษหนักจนเสียของทั้งแปลงจากการพลาดครั้งเดียว
- เหมือนเกมที่มีอยู่แล้วจนเป็นการลอก

## ที่ปล่อยให้คนลงมือทำตัดสินใจ

สีและรูปทรงชั่วคราว ตำแหน่งสิ่งของบนแผนที่ รูปแบบเมนูร้านและหน้าสรุปวัน ชื่อฟังก์ชันและการแบ่งไฟล์ย่อย
