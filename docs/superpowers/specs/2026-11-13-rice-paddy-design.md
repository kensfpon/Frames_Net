# ขั้นที่ 4: นาข้าว

วันที่: 2026-11-13 · สถานะ: กติกาและหน้าต่างชั่วคราวเสร็จแล้ว ภาพรอ Codex (ดู `docs/handoff/codex-graphics-handoff.md`)

เจ้าของโปรเจกต์สั่งให้ทำขั้นนี้ต่อจนเสร็จโดยไม่ต้องรออนุมัติแบบ ทุกอย่างในเอกสารนี้จึงเป็นการตัดสินใจของ Claude
และปรับได้หลังลองเล่น

## ทำไม

นาข้าวเป็นหัวใจของชีวิตชาวนาไทย และเป็นที่ที่ภัยแล้งกับน้ำท่วมมีความหมาย (ขั้นที่ 2 เลื่อนสองเรื่องนี้มาไว้ที่นี่)
ผักต้องรดน้ำทุกวันทีละช่อง ข้าวต่างออกไป: ผู้เล่นดูแล "ระดับน้ำทั้งแปลง" ผ่านประตูน้ำ แล้ววางแผนตามพยากรณ์อากาศ

## วิธีสร้างที่พิจารณา

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| 1. ระดับน้ำต่อแปลง คุมด้วยประตูน้ำ 3 จังหวะ (ปิด / รับน้ำ / ระบาย) **(เลือกทางนี้)** | ต่างจากแปลงผักชัดเจน ใช้พยากรณ์อากาศวางแผนได้ แล้งและท่วมเกิดจากระบบเดียวกัน | ต้องอธิบายระดับน้ำบนจอ |
| 2. ข้าวเป็นพืชอีกชนิดในแปลงผัก รดน้ำรายช่อง | ทำง่ายสุด | ไม่ต่างจากผัก ไม่มีแล้งหรือท่วม |
| 3. จำลองน้ำไหลจริงระหว่างช่อง | สมจริงที่สุด | งานใหญ่มาก ปรับสมดุลยาก |

## สิ่งที่เปลี่ยนจากแบบร่างแรก

แบบร่างแรกวางทุ่งนาเป็นโซนตารางช่อง 20×12 ที่เดินออกขอบจอไปหา และปลูกข้าวทีละช่อง
ระหว่างนั้นเกมเปลี่ยนไปใช้แผนที่ภาพวาดกับระบบ region ของ Codex ซึ่งไม่มีตารางช่องนอกแปลงผัก แบบจึงปรับเป็น:

- **หนึ่งแปลงคือหนึ่งหน่วย** ไถ ดำ และเกี่ยวทั้งแปลงในครั้งเดียว ไม่มีข้าวรายช่อง
- เข้าถึงผ่านป้าย "นาข้าว" ในไร่ ซึ่งเปิดหน้าต่างจัดการ เมื่อมีภาพทุ่งนาแล้วค่อยย้ายไปเป็น region ของตัวเอง
- **ข้าวไม่เหี่ยวตามฤดู** ดำนาได้เฉพาะฤดูร้อนและฤดูฝน แต่ข้าวที่ดำแล้วโตต่อและเกี่ยวได้ในฤดูหนาว
  เหมือนนาปีจริงที่ดำหน้าฝนแล้วเกี่ยวหน้าหนาว

## ข้าว

| | |
|---|---|
| ซื้อ | กล้าข้าวมัดละ ฿60 ดำได้หนึ่งแปลง ขายฤดูร้อนและฤดูฝน |
| โต | 10 คืนที่น้ำดี |
| ผลผลิต | 12 ถังต่อแปลง ลดคืนละ 1 ทุกคืนที่น้ำเสีย ต่ำสุด 4 |
| ขาย | ข้าวเปลือก ฿45 ต่อถัง ผ่านลังส่งของ |
| แปลง | 3 แปลง |

ขั้นตอน: เปิดประตูน้ำให้น้ำเข้า → ไถ → ดำนา (ต้องมีน้ำตื้นถึงน้ำลึก) → คุมระดับน้ำทุกวัน → เกี่ยว

แรงที่ใช้: ไถ 12 · ดำนา 10 · เกี่ยว 10 ถ้านาแห้งหรือน้ำตื้น, 16 ถ้ายังมีน้ำขัง
วันแดดจัดงานในนาเหนื่อยขึ้น 3 จอบเหล็กจากช่างคำลดแรงไถ 3

ข้าวหนึ่งแปลงให้กำไรราว ฿480 จากแรง 32 หน่วยใน 11 วัน ต่อแรงแล้วคุ้มกว่าผักมาก แต่มีแค่ 3 แปลง
และต้องแวะดูทุกวัน จึงเป็นรายได้เสริมที่มั่นคง ไม่ใช่ทางรวยเร็ว

## ระดับน้ำ

ระดับ 0–4: แห้ง · น้ำตื้น · น้ำพอดี · น้ำลึก · น้ำท่วม ข้าวโตเมื่อระดับอยู่ที่ 1–3

ทุกคืน ระดับน้ำของทุกแปลงเปลี่ยนตาม ประตูน้ำ + อากาศของวันรุ่งขึ้น (ซึ่งรู้ล่วงหน้าจากพยากรณ์):

| ประตูน้ำ | ผล | | อากาศ | ผล |
|---|---|---|---|---|
| ปิด | 0 | | แดด | −1 |
| เปิดรับน้ำ | +2 | | แดดจัด | −2 |
| ระบายน้ำออก | −2 | | ฝน | +1 |
| | | | พายุฝน | +2 |

จากนั้นข้าวที่ยังไม่สุกดูระดับใหม่: อยู่ในช่วงดี → โต 1 ขั้นและหายเครียด, แห้งหรือท่วม → เครียดเพิ่ม 1 และเสียผลผลิต 1
เครียดครบ 3 คืนติดกันข้าวตายทั้งแปลง ต้องไถกลบ ข้าวที่สุกแล้วไม่ได้รับผลจากน้ำ

จากน้ำระดับดีใด ๆ มีประตูน้ำอย่างน้อยหนึ่งแบบที่รักษาน้ำไว้ในช่วงดีได้เสมอ ไม่ว่าพยากรณ์จะเป็นอะไร
นาข้าวจึงไม่มีดวง: เสียหายได้เฉพาะเมื่อผู้เล่นไม่ได้มาดูหรืออ่านพยากรณ์ผิด

ผลที่ได้: ฤดูร้อนต้องเปิดรับน้ำสลับกับปิดเพื่อสู้แดด ฤดูฝนต้องปิดหรือระบายก่อนฝนและพายุ

## หน้าจอ (ชั่วคราว)

- ป้าย "นาข้าว" ทางขวาของแปลงผัก เปิดหน้าต่างที่แสดงทั้ง 3 แปลง
- แต่ละแปลงบอกสถานะข้าว ระดับน้ำตอนนี้ และ "คืนนี้จะเป็น..." พร้อมเตือนถ้าข้าวจะใบเหลือง
- ปุ่มประตูน้ำทั้ง 3 แบบเขียนผลของคืนนี้ไว้บนปุ่ม เช่น "เปิดรับน้ำ → น้ำลึก"
- หน้าสรุปตอนเช้าบอกแปลงที่ข้าวใบเหลือง ตาย หรือสุกพร้อมเกี่ยว
