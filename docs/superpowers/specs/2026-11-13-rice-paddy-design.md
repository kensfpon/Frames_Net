# ขั้นที่ 4: นาข้าว

วันที่: 2026-11-13 · สถานะ: สร้างเสร็จ 2026-11-13

เจ้าของโปรเจกต์สั่งให้ทำขั้นนี้ต่อจนเสร็จแล้ว push โดยไม่ต้องรออนุมัติแบบ ทุกอย่างในเอกสารนี้จึงเป็นการตัดสินใจของ Claude
และปรับได้หลังลองเล่น

## ทำไม

นาข้าวเป็นหัวใจของชีวิตชาวนาไทย และเป็นที่ที่ภัยแล้งกับน้ำท่วมมีความหมาย (ขั้นที่ 2 เลื่อนสองเรื่องนี้มาไว้ที่นี่)
ผักต้องรดน้ำทุกวันทีละช่อง ข้าวต่างออกไป: ผู้เล่นดูแล "ระดับน้ำทั้งแปลง" ผ่านประตูน้ำ แล้ววางแผนตามพยากรณ์อากาศ

## วิธีสร้างที่พิจารณา

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| 1. ระดับน้ำต่อแปลง คุมด้วยประตูน้ำ 3 จังหวะ (ปิด / รับน้ำ / ระบาย) **(เลือกทางนี้)** | ต่างจากแปลงผักชัดเจน ใช้พยากรณ์อากาศวางแผนได้ แล้งและท่วมเกิดจากระบบเดียวกัน | ต้องอธิบายระดับน้ำบนจอ |
| 2. ข้าวเป็นพืชอีกชนิดในแปลงผัก รดน้ำรายช่อง | ทำง่ายสุด | ไม่ต่างจากผัก ไม่มีแล้งหรือท่วม |
| 3. จำลองน้ำไหลจริงระหว่างช่อง | สมจริงที่สุด | งานใหญ่มาก ปรับสมดุลยาก |

## แผนที่หลายโซน

- แผนที่มี 2 โซน ขนาด 20×12 เท่ากัน: **บ้าน** (เดิม) และ **ทุ่งนา** (ใหม่)
- เดินออกขอบขวาของบ้านที่แถว 6–7 ไปทุ่งนา และออกขอบซ้ายของทุ่งนาที่แถวเดียวกันกลับบ้าน มีป้ายบอกทาง
- เข้านอนหรือล้มหลับในทุ่งนาแล้วตื่นที่บ้านเสมอ โซนที่อยู่ไม่ถูกเซฟ
- ทุ่งนา: คลองส่งน้ำแถวบนสุด ประตูน้ำ 3 บานใต้คลอง และแปลงนา 3 แปลง แปลงละ 4×5 ช่อง ทางเดินระหว่างแปลงคือคันนา
- คลองตกปลาได้ ใช้ปลาชุดเดียวกับหนองน้ำ

## ข้าว

| | |
|---|---|
| ซื้อ | ต้นกล้าข้าว ฿15 ที่แผงขาย ฤดูร้อนและฤดูฝน |
| โต | 10 คืนที่น้ำดี |
| ขาย | ข้าว ฿50 ต่อกอ |
| ฤดู | ร้อน ฝน (เข้าฤดูหนาวแล้วเหี่ยว เหมือนพืชอื่น) |

ขั้นตอน: ไถด้วยจอบ → เปิดประตูน้ำให้น้ำเข้า → ดำนา (ต้องมีน้ำอย่างน้อย "น้ำตื้น") → คุมระดับน้ำทุกวัน → เก็บเกี่ยวด้วยมือ

- ปลูกข้าวในแปลงผักไม่ได้ ปลูกผักในนาไม่ได้ บัวรดน้ำใช้กับนาไม่ได้
- ราคาข้าวต่อวันต่ำกว่าผัก แต่ไม่ต้องรดน้ำรายช่อง จึงคุ้มแรงเมื่อทำแปลงใหญ่

## ระดับน้ำ

ระดับ 0–4: แห้ง · น้ำตื้น · น้ำพอดี · น้ำลึก · น้ำท่วม ข้าวโตเมื่อระดับอยู่ที่ 1–3

ทุกคืน ระดับน้ำเปลี่ยนตาม ประตูน้ำ + อากาศของวันรุ่งขึ้น (ซึ่งรู้ล่วงหน้าจากพยากรณ์):

| ประตูน้ำ | ผล | | อากาศ | ผล |
|---|---|---|---|---|
| ปิด | 0 | | แดด | −1 |
| เปิดรับน้ำ | +2 | | แดดจัด | −2 |
| ระบายน้ำออก | −2 | | ฝน | +1 |
| | | | พายุฝน | +2 |

จากนั้นข้าวแต่ละกอดูระดับใหม่: อยู่ในช่วงดี → โต 1 ขั้นและหายเครียด, แห้งหรือท่วม → เครียดเพิ่ม 1
เครียดครบ 3 คืนติดกันจึงตาย พลาดคืนเดียวแค่ไม่โตและใบเหลือง ข้าวที่สุกแล้วไม่ได้รับผลจากน้ำ

ผลที่ได้: ฤดูร้อนต้องเปิดรับน้ำเกือบตลอดเพื่อสู้แดด ฤดูฝนต้องปิดหรือระบายก่อนพายุ

## หน้าจอ

- กด E ที่ประตูน้ำเพื่อสลับ ปิด → รับน้ำ → ระบาย
- ยืนในแปลงหรือหันหน้าเข้าประตูน้ำ จะเห็นแถบข้อมูล: แปลงที่เท่าไร ระดับน้ำตอนนี้ ประตูน้ำ และ "คืนนี้น้ำจะเป็น..." พร้อมเตือนถ้าจะแล้งหรือท่วม
- สีแปลงที่ไถแล้วบอกระดับน้ำ ข้าวที่เครียดเป็นสีเหลือง
- หน้าสรุปตอนเช้าบอกแปลงที่แล้งหรือท่วม จำนวนกอที่ใบเหลืองและที่ตาย
