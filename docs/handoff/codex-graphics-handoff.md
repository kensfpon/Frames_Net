# ส่งต่องานภาพและหน้าจอ: นาข้าว สวนผลไม้ งานประเพณี

ถึง: Codex (ผู้ดูแลภาพ เสียง และหน้าจอของเกม) · จาก: Claude · วันที่: 2026-11-13

ระบบเกมสามระบบใหม่เขียนเสร็จและทดสอบแล้ว แต่ยังใช้หน้าต่างข้อความธรรมดาเป็นของชั่วคราว
เอกสารนี้บอกว่าต้องวาดอะไร อ่านข้อมูลจากตรงไหน และต่อเข้ากับปุ่มอย่างไร

## สรุปสั้น

| ระบบ | ผู้เล่นทำอะไร | เข้าได้จาก (ชั่วคราว) |
|---|---|---|
| นาข้าว | ไถ ดำนา ตั้งประตูน้ำทุกวันตามพยากรณ์ เกี่ยวข้าว | ป้าย "นาข้าว" ในไร่ ขวาของแปลงผัก |
| สวนผลไม้ | ซื้อกิ่งพันธุ์ ปลูก รดน้ำต้นอ่อน ใส่ปุ๋ย เก็บผล | ป้าย "สวนผลไม้" ในไร่ ซ้ายของแปลงผัก |
| งานประเพณี | ไปร่วมงานปีละ 6 งานที่หมู่บ้าน | ป้าย "ลานงานประเพณี" กลางหมู่บ้าน |

ตอนนี้ทั้งสามเปิดเป็นหน้าต่าง `<dialog>` เดิมของเกม ใช้คลาส `.row` `.action` `.actions` `.detail` `.purse`
ที่มีอยู่แล้ว ยังไม่มีภาพใหม่แม้แต่ภาพเดียว

## ข้อมูลที่ใช้วาด

ทุกอย่างอยู่ใต้ `state.estate` (เซฟรุ่น 4 เซฟรุ่นเก่าแปลงขึ้นเองโดยเริ่มจากนาและสวนว่าง)

### นาข้าว: `state.estate.paddy`

```ts
paddy.seedlings            // มัดกล้าในมือ
paddy.plots[0..2] = {
  stage: 'fallow' | 'ploughed' | 'planted',
  water: 0..4,             // แห้ง น้ำตื้น น้ำพอดี น้ำลึก น้ำท่วม (WATER_NAMES)
  gate: 'closed' | 'in' | 'out',
  growth: 0..10,           // คืนที่น้ำดี ครบ 10 คือสุก
  stress: 0..3,            // คืนที่น้ำเสียติดกัน ครบ 3 ข้าวตาย
  lost: number,            // คืนที่น้ำเสียรวม ลดผลผลิตคืนละ 1
  dead: boolean,
}
```

ฟังก์ชันช่วยจาก `src/rules/paddy.ts`: `riceRipe(plot)`, `expectedYield(plot)`, `goodWater(level)`,
`waterAfter(water, gate, weather)` (ระดับน้ำพรุ่งนี้ ใช้ทำตัวอย่างบนปุ่มประตูน้ำ), `riceInSeason(state)`

ภาพที่ต้องบอกผู้เล่นให้ได้ในแวบเดียว:

1. ระดับน้ำ 5 ระดับของแต่ละแปลง
2. ประตูน้ำ 3 สถานะ
3. ข้าว: ต้นกล้า → แตกกอ → ออกรวง → สุกเหลือง (แบ่งจาก `growth` 0–10) ข้าวใบเหลืองเมื่อ `stress > 0` และข้าวตาย
4. คำเตือนก่อนนอน: `waterAfter(plot.water, plot.gate, state.forecast)` ออกนอกช่วง 1–3 ขณะข้าวยังไม่สุก

### สวนผลไม้: `state.estate.orchard`

```ts
orchard.saplings = { banana, mango, longan, orange }   // กิ่งพันธุ์ในมือ
orchard.slots[0..5] = null | {
  id: 'banana' | 'mango' | 'longan' | 'orange',
  age: number,       // วันที่ได้น้ำ ถึง growDays คือโตเต็มที่
  watered: boolean,  // วันนี้ได้น้ำแล้ว (มีผลเฉพาะต้นอ่อน)
  bloom: number,     // คืนที่ผ่านไปในรอบออกผลนี้
  fruit: 0..9,       // ผลสุกบนต้น
  fed: boolean,      // ใส่ปุ๋ยแล้ว รอบหน้าได้ผลเพิ่ม
}
```

ฟังก์ชันช่วยจาก `src/rules/orchard.ts`: `isGrown(tree)`, `bearsIn(tree, season)`, `nightsToFruit(tree, season)`

ภาพที่ต้องมี: หลุมว่าง ต้นอ่อน (ควรเห็นว่าวันนี้ได้น้ำหรือยัง) ต้นโต ต้นโตมีผล (จำนวนผลพอประมาณได้)
เครื่องหมายใส่ปุ๋ยแล้ว และต้นนอกฤดู (ไม่ออกดอก) ทั้ง 4 ชนิด

### งานประเพณี: `state.estate.festivals`

`festivals.joined[id]` เก็บวันที่ร่วมงานล่าสุด (0 = ยังไม่เคย) ฟังก์ชันช่วยจาก `src/rules/festival.ts`:
`festivalOn(day)`, `nextFestival(day)`, `daysUntil(id, day)`, `festivalHours(id)`,
`festivalClosed(state)` (คืนเหตุผลที่ยังร่วมไม่ได้ หรือ `null` เมื่อร่วมได้)

| งาน | วัน | เวลา | ต้องเตรียม | ได้ |
|---|---|---|---|---|
| สงกรานต์ ปี๋ใหม่เมือง | ร้อน 6 | 09–18 | ไม่มี | พลังงาน +25 |
| บุญบั้งไฟ | ร้อน 12 | 10–18 | ไม้ 3 | พรุ่งนี้ฝนตก |
| พิธีแรกนาขวัญ | ฝน 2 | 08–16 | ไม่มี | กล้า 1 มัด ข้าวในนาโต +1 คืน |
| แข่งเรือยาว | ฝน 11 | 10–18 | พลังงาน 30 | ชนะ ฿200 แพ้ ฿40 |
| ยี่เป็ง ลอยโคม | หนาว 3 | 17–23 | ฿30 | มิตรภาพ +3 |
| ตานข้าวใหม่และประกวดพืชผล | หนาว 10 | 09–17 | ของดีสุดในกระเป๋า 1 ชิ้น | 4 เท่าของราคาขาย |

วันพายุฝนงานงด ทุกงานเพิ่มมิตรภาพกับมะลิและลุงชัย และกินเวลา 90 นาที

### ของขาย: `state.estate.goods` และ `goodsShipping`

ข้าวและผลไม้ขายผ่านลังส่งของเท่านั้น (`shipAll` ย้ายให้แล้ว และ `endDay` จ่ายเงินตอนเช้า)
พ่อค้าในกาดยังไม่รับซื้อ ถ้าอยากให้รับซื้อทันทีต้องเพิ่มกติกาก่อน

## คำสั่งจากปุ่ม

ปุ่มใดก็ตามที่มี `data-cmd="chore-<คำสั่ง>"` จะวิ่งไป `chore(state, '<คำสั่ง>')` ผ่าน `FarmScene.command`
แล้วเปิดหน้าต่างเดิมซ้ำ แสดง `message` และเล่นเสียง `select` หรือ `error` ตาม `ok`

```
paddy:buy                    paddy:plough:<แปลง>      paddy:plant:<แปลง>
paddy:gate:<แปลง>:<closed|in|out>                     paddy:harvest:<แปลง>
orchard:buy:<ต้น>            orchard:plant:<หลุม>:<ต้น>
orchard:water:<หลุม>         orchard:feed:<หลุม>
orchard:pick:<หลุม>          orchard:fell:<หลุม>
festival:join
```

แปลงและหลุมนับจาก 0 ถ้าจะทำให้คลิกบนฉากได้โดยตรง เรียก `chore()` จากฉากได้เลยโดยไม่ต้องมีหน้าต่างเปิดอยู่
(เงื่อนไข `if (!panel) return` ใน `FarmScene.command` มีไว้สำหรับปุ่มในหน้าต่างเท่านั้น)

ข่าวตอนเช้าอยู่ใน `DaySummary.notes: string[]` เช่น ข้าวใบเหลือง ข้าวสุก ผลไม้ร่วง และประกาศงานประเพณี

## ข้อเสนอเรื่องหน้าจอ

1. ทำให้นาและสวนเป็น region จริง: เพิ่ม `paddy` และ `orchard` ใน `regionNames` (`src/rules/country.ts`)
   และ `layouts` (`src/presentation/regions.ts`) แล้วย้ายป้ายจากไร่ไปเป็นทางเดิน `to-paddy` `to-orchard`
   ตำแหน่งป้ายตอนนี้เป็นของชั่วคราว: นาข้าว (1089, 470) สวนผลไม้ (332, 548) ลานงาน (520, 560)
2. ให้ผู้เล่นคลิกแปลงนา ประตูน้ำ และต้นไม้บนฉากได้โดยตรง ส่วนหน้าต่างเหลือไว้เป็นรายละเอียด
3. ปุ่มประตูน้ำควรบอกผลของคืนนี้เสมอ ("เปิดรับน้ำ → น้ำลึก") เพราะนี่คือการตัดสินใจหลักของนาข้าว
4. วันที่มีงานประเพณีควรเห็นจากไร่ได้เลย เช่น ธงที่ป้ายไปหมู่บ้าน และแต่งลานหมู่บ้านตามงาน
5. สมุดบันทึกฟาร์มควรมีแถว "งานประเพณีถัดไป" จาก `nextFestival(state.day)`
6. หน้าวิธีเล่นยังไม่พูดถึงสามระบบนี้

## สิ่งที่กติกามีแต่หน้าจอยังไม่มี

- `orchard:fell:<หลุม>` โค่นต้นไม้ ยังไม่มีปุ่ม เพราะต้องมีหน้าต่างยืนยันก่อน (ต้นหนึ่งใช้เวลาโต 6–12 วัน)
- จำนวนข้าวและผลไม้ในลังไม่ได้รวมในแถว "รอส่งขายในลัง" เดิม แต่แสดงแยกใน `estateBag()`
